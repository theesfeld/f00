f00 · give

If you give, give quiet.

The work is free. There is no paywall and no product to buy. Support is optional — one collective pool, never per project. Split evenly among stewards. No cup on the sidewalk.

One pool

Every donate link on every f00 site points here. There is no tip jar for a single logo. If something arrives, it is shared evenly across the collective — like bread, not like equity.

How (local / diy)

We stay out of the big payment conglomerates when we can. Prefer paths that stay small, local, and hard to own.

  • Monero (XMR) — address on request via tj@f00.sh
  • Cash in person or by post — details on request
  • Other diy channels when they stay free of the mall

Ask: tj@f00.sh · @lameserver

Addresses rotate. We do not keep a permanent public wallet burned into every screenshot. Write first; we answer with the current way.

What this is not

Not a subscription. Not a crowdfunding campaign. Not sponsorship tiers. Not a tax on using the work. The projects stay open whether you give or not. If you never send a thing, you are still welcome to use everything we ship.

For love

The default is zero. Giving is a choice, not a duty. We do not beg. We do not panhandle. We make the thing, put it down, keep walking.
