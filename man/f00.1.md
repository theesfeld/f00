# f00(1) — brand hub for f00.sh products

## NAME

f00 — brand hub and shared theme host for f00 products

## SYNOPSIS

```text
# Public surfaces (no CLI binary)
https://f00.sh
https://f00.sh/catalog.json
https://f00.sh/theme/f00-theme.css
```

## DESCRIPTION

f00 is the brand landing for products under org f00-sh.

The hub shows a splash and released product cards only.
Install instructions live on each product site.

**ONE shared CSS:** https://f00.sh/theme/f00-theme.css (all product subdomains). **Default theme:** Heartbox + Bleach layout. Color tokens come from
github.com/f00-sh/heartbox (`palette/heartbox.json`).
Every product site loads the catalog theme CSS first.
Type roles: Onyx for the f00 logo only; zine mono for body;
chip mono for headers, footers, and nav.

## FILES

| Path | Purpose |
|---|---|
| `site/catalog.json` | Product inventory + theme pointer (SSOT) |
| `site/theme/f00-theme.css` | Shared brand theme (Heartbox colors) |
| `site/assets/` | Favicon, BIMI, org avatar, Onyx font |
| `scripts/sync-from-catalog.py` | Regenerate hub cards + README + AGENTS |
| `scripts/enroll-product.py` | Add product + inject theme link |
| `file_id.diz` | Release scene card |

## CATALOG

Edit `site/catalog.json`, then run:

```text
python3 scripts/sync-from-catalog.py
```

Only products with `status=released` appear on the hub grid.
