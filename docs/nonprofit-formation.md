# f00 collective — non-profit formation (working notes)

**Public plan lives on the hub:**

- <https://f00.sh/plan> · plain text <https://f00.sh/plan.md>
- Bond / methodology: <https://f00.sh/constitution> · <https://f00.sh/constitution.md>

**Not legal advice.** Ops sketch so the collective can receive and pass
support for open art/tech work without becoming a company. Talk to a
lawyer who knows exempt orgs before filing anything.

**Honesty law:** never claim 501(c)(3) / registered charity / tax-deductible
status on the world-facing site until it is true and published.

## Why bother

- Attract **project funding** (grants, gifts) into a **shared pool**.
- Issue receipts / report cleanly if donors care about formal status.
- Stay consistent with the [constitution](https://f00.sh/constitution):
  MIT, open, no paywalls, no owners, one pool, open ledger, no gods.

Why *not* rush:

- Federal charity status is paperwork — tension with “out of the mall.”
- Form without discipline and you get a **company with softer language**.

## Fit check (f00 constraints)

| Constraint | Implication |
|------------|-------------|
| Art + tech + open tools | Purpose language: **education, arts, science** — not “sell software” |
| MIT / free forever | Compatible with public benefit; avoid exclusive licenses |
| Fund projects | Prefer **grants to stewards/projects** with open deliverables |
| No owners / no leads | Bylaws: **stewards**, one person one vote, no super-vote class |
| Even-split gifts | Policy: unrestricted gifts → pool → split or project grants |
| No conglomerate rails | Can still take XMR/cash; formal org may *also* open a bank later |

## Paths (pick one to start)

### A. Fiscal sponsorship (fastest, least identity load)

Partner with an existing public charity that sponsors art/tech projects.
They hold the tax ID; f00 is a **sponsored project**.

### B. Own public-benefit corporation + federal exemption

Form a state nonprofit corporation, adopt bylaws, apply for federal tax
exemption (often called 501(c)(3) **only after** granted). Bylaws must
encode f00 politics in plain legal clothes — stewards, one person one
vote, open work, open ledger, dissolution to another public-benefit body.

### C. Unincorporated association + diy only

Stay informal; XMR/cash only; no tax receipts. Purest gut; weakest funding.

### D. Cooperative / mutual (different tool)

Not a substitute for a public-benefit gift shell.

## Recommended sequence

See <https://f00.sh/plan> for the living public sequence. Summary:

1. Diy give live (`f00.sh/donate`).
2. Open ledger complete.
3. Constitution + steward practice public.
4. Proposal → open vote → land.
5. Optional fiscal sponsor pilot.
6. Own shell only if still needed — then publish status honestly.

## Formation checklist (own shell)

- [ ] Purpose statement (arts + open tech education; public benefit)
- [ ] Name / DBA availability in home state
- [ ] Incorporators + initial board (need people who accept duty)
- [ ] Articles of incorporation (state)
- [ ] Bylaws: stewards, votes, no owners, MIT/open mandate, **no-profit dissolution**
- [ ] Dissolution clause: never private residual; transfer to 501(c)(3) **or** liquidate and donate **all** remaining funds to other 501(c)(3)s (preferred: Sisters of the Road, Food Not Bombs / qualifying host, more TBD)
- [ ] Conflict-of-interest policy
- [ ] EIN (IRS)
- [ ] Form 1023 or 1023-EZ
- [ ] State charity registration if soliciting donations in-state
- [ ] Bank (when ready) + bookkeeping + annual 990
- [ ] Grant policy: who can apply, open deliverables, no private inurement
- [ ] Public donate / plan pages still one pool and true about status

## What the pool is for (program spend)

Gifts and any physical-sales surplus go back into **more released work**,
not private income. Free digital · physical for cost recovery. No profit
distributions. Open ledger mandatory: <https://f00.sh/ledger>.

## Anti-patterns

- Claiming charity status before recognition
- Per-project tip jars
- “Founder” super-vote
- Closed source “for sustainability”
- Paywall “members area”
- Discord as the only vote record
- Private books alongside the public ledger
- Becoming a pass-through for one person’s lifestyle
